JVM 구동 애니메이션: java -cp app.jar com.example.Main

구성도는 고정하고, 번호가 붙은 점(main 스레드)이 호출을 따라 한 칸씩 움직입니다. 구간에 쓰이는 구성 요소는 색이 켜지고, 지금 일하는 곳은 주황 테두리로 표시돼요. JDK 21 HotSpot 기준.
