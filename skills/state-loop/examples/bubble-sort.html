버블 정렬, 무한히 반복하다

알고리즘 한 스텝을 상태로 표현하고 그 상태를 그림으로 옮기는 최소 엔진입니다. 정렬이 끝나면 잠깐 멈췄다가 배열을 다시 섞어 처음부터 반복합니다 — 이 리셋이 있어야 루프가 무한해집니다.

네 조각으로 나뉩니다. 알고리즘이 바뀌어도 STEP 하나만 새로 짜면 되고, RENDER·LOOP는 그대로 재사용합니다.

STATE

정렬 배열, 비교 중인 인덱스, 비교·스왑 횟수, 완료 여부. 알고리즘이 "지금 어디에 있는지"를 통째로 담는 순수 객체입니다.

STEP

한 번 호출하면 정확히 한 번의 비교(필요하면 스왑)만 진행합니다. 알고리즘 로직은 여기 한 곳에만 있어서, 다른 알고리즘으로 바꿀 땐 이 함수만 새로 짜면 됩니다.

RENDER

state.arr의 순서를 읽어 각 막대를 자기 슬롯으로 옮길 뿐, 정렬 로직은 전혀 모릅니다. CSS transition이 이동을 매끄럽게 그려줍니다.

LOOP

state.sorted가 되면 잠깐 멈췄다가 배열을 다시 섞어 state를 초기화합니다. 이 리셋이 있어야 "무한히 도는 이미지"가 됩니다.

실제로 쓰인 STEP 함수 — 이 화면이 매 260ms마다 부르는 전부입니다

function doStep(state) {
  const { arr, n } = state;
  if (state.j > n - state.i - 2) {
    state.i += 1; state.j = 0;
    if (state.i >= n - 1) { state.sorted = true; state.phase = 'sorted'; state.active = []; return; }
  }
  const a = state.j, b = state.j + 1;
  state.active = [a, b];
  state.comparisons += 1;
  if (arr[a].value > arr[b].value) {
    [arr[a], arr[b]] = [arr[b], arr[a]];
    state.phase = 'swap'; state.swaps += 1;
  } else {
    state.phase = 'compare';
  }
  state.j += 1;
}
O(n²) 비교 · 매 루프 시작마다 12개 값을 다시 섞어 처음부터 재생합니다.
