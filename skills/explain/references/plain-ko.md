# 쉬운 기술 한국어 (1단계 글, 한국어)

ASD-STE100(Simplified Technical English)의 규칙 범주를 한국어 기술 문장에 옮긴 이 저장소의 규칙이다. **공식 규격이 아니다.** STE는 영어만 정의한다. 숫자 한도는 STE의 단어 수 한도를 한국어 어절로 옮겨 이 스킬이 정한 값이다.

STE의 목표는 하나다. 읽는 사람이 되묻지 않고 한 가지로만 읽게 한다. 그래서 뜻이 여럿인 단어와 구조가 여럿으로 읽히는 문장을 없앤다.

## 강도

| 강도 | 언제 | 적용 |
|---|---|---|
| 80% (기본) | 설명문, 문서, 영상 내레이션 | 구조 규칙은 모두 지킨다. 어휘 규칙은 권고 |
| 엄격 | 절차서, 경고문, 에러 메시지, 운영 지침 | 구조 규칙과 어휘 규칙을 모두 지킨다 |

## 구조 규칙 (항상)

1. **문장 하나에 내용 하나.** 절차문은 문장 하나에 지시 하나만 둔다. 동시에 해야 하는 동작만 예외다.
2. **문장 길이.** 절차문은 12어절, 설명문은 15어절을 넘기지 않는다. 넘으면 문장을 나눈다.
3. **문단 길이.** 문단 하나는 주제 하나, 6문장 이내.
4. **능동문, 주어를 밝힌다.** "~되어진다", "~에 의해 ~된다"를 쓰지 않는다. 누가 하는지 모르면 문장이 두 가지로 읽힌다.
5. **조건을 앞에.** "~하면, ~한다" 순서로 쓴다. 조건이 문장 끝에 붙으면 동작을 먼저 해 버린다.
6. **명사 나열은 3개까지.** "결제 승인 요청 처리 결과 통보"처럼 명사를 4개 이상 잇지 않는다. 조사와 동사로 풀어 쓴다.
7. **같은 대상은 같은 말로.** 한 글 안에서 "요청", "호출", "콜"을 섞지 않는다. 처음 쓴 말을 끝까지 쓴다.
8. **경고는 지시 먼저, 이유 다음.** "브레이크가 식기 전에 만지지 마십시오. 뜨거운 부품은 화상을 입힙니다."
9. **복잡한 내용은 세로 목록으로.** 순서가 있으면 번호 목록, 없으면 글머리표.
10. **사실, 조건, 범위 한정어를 지우지 않는다.** 다시 쓰기이지 요약이 아니다. 줄이면 정밀도가 깨지는 문장은 길게 두고 그 사실을 알린다.

## 어휘 규칙 (80%에서는 권고)

뜻이 하나로 읽히는 쉬운 말을 고르고, 같은 뜻에는 같은 말을 쓴다.

| 피할 말 | 쓸 말 |
|---|---|
| ~에 대하여, ~에 대한 | ~를, ~의 |
| ~를 통해 | ~로 |
| ~에 있어서 | ~에서 |
| 수행하다, 진행하다, 실시하다 | 하다, 또는 구체적인 동사 (보낸다, 지운다) |
| ~하는 것이 가능하다 | ~할 수 있다 |
| ~할 필요가 있다 | ~해야 한다 |
| ~적인 (기능적인, 효율적인) | 뜻을 풀어 쓴다 |
| 상기, 하기, 동 | 위, 아래, 이 |
| 및 | 와/과, 그리고 |

## 예

| 전 | 후 |
|---|---|
| 운영자는 작업 개시 이전에 유압 저장소가 보충되어 있는지에 대한 확인을 수행하는 것이 필요하다. | 작업을 시작하기 전에 유압 저장소가 가득 찼는지 확인하십시오. |
| 결제 승인 요청 처리 결과 통보 지연 시 재시도가 수행됩니다. | 승인 결과 통보가 늦으면, 시스템이 통보를 다시 보냅니다. |
