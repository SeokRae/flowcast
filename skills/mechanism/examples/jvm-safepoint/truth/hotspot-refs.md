# HotSpot 소스 참조 (jvm-safepoint)

그림의 규칙이 HotSpot 21.0.1의 어느 줄에서 나오는지 가리키는 목록이다. OpenJDK 소스(GPLv2 + Classpath Exception)는 이 저장소(MIT)에 옮기지 않는다. 코드 원문 대신 고정 태그의 줄 범위 링크, 함수명, 그 줄이 하는 일의 요약만 적는다.

- 저장소: openjdk/jdk21u
- 태그: `jdk-21.0.1+12` (태그 객체 `d4397127d8f20451382a8cc14b8f8dc0cb386ea9`, 커밋 `060c4f7589e7f13febd402f4dac3320f4c032b08`)
- 실행한 빌드: Amazon Corretto 21.0.1.12.1 (`21.0.1+12-LTS`), macOS arm64
- 원문 확인: `bash truth/fetch-hotspot.sh`로 아래 파일을 임시 폴더에 받은 뒤 `node check-source.mjs`. 받은 파일의 SHA-256은 `fetch-hotspot.sh`에 고정해 두었고, `check-source.mjs`는 표의 "대조 식별자"가 각 줄 범위 안에 있는지와 모델이 기대는 줄들을 확인한다
