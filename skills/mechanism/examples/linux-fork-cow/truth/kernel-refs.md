# 리눅스 커널 소스 참조 (linux-fork-cow)

그림의 규칙이 리눅스 7.0.14의 어느 줄에서 나오는지 가리키는 목록이다. 커널 소스(GPLv2)는 이 저장소(MIT)에 옮기지 않는다. 코드 원문 대신 고정 태그의 줄 범위 링크, 함수명, 그 줄이 하는 일을 우리 말로 쓴 요약만 적는다.

- 저장소: linux stable (`git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git`)
- 태그: `v7.0.14` (태그 객체 `b38d6c0b6e7f406a7feb7d46f184ec3edaac8c3b`, 커밋 `458c6079fc1d41d564c37679c8ace02cd83ee817`)
- 실행한 빌드: Docker Desktop의 `7.0.14-linuxkit #1 SMP PREEMPT`, arm64. linuxkit 빌드가 패치를 몇 개 더 얹었을 수 있다. 줄 참조는 upstream 태그이고, 측정값(`truth/*.log`, `truth/ftrace-*.txt`)은 linuxkit 빌드에서 나왔다
- 원문 확인: `bash truth/fetch-kernel.sh`로 아래 파일을 임시 폴더에 받은 뒤 `node check-source.mjs`. 받은 파일의 SHA-256은 `fetch-kernel.sh`에 고정해 두었고, `check-source.mjs`는 표의 "대조 식별자"가 각 줄 범위 안에 있는지와 모델이 기대는 줄들을 확인한다
- ftrace로 볼 수 없는 함수: `wp_page_copy`, `wp_page_reuse`, `wp_can_reuse_anon_folio`, `copy_pte_range`, `copy_present_ptes`는 이 빌드의 `available_filter_functions`에 없다(인라인). 어느 길로 갔는지는 그 안에서 불리는 함수(`copy_user_highpage`, `folio_move_anon_rmap`, `lru_add_drain`)와 아래 줄 범위로 정했다
